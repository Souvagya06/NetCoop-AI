# Dataset

Generated by `scripts/generate_dataset.py` into `backend/datasets/generated/`:
`telemetry_train.csv` (seed 42, 150 snapshots/scenario, 300 normal), `telemetry_test.csv` and `telemetry_dataset.json` (seed 2026, 60/scenario, 120 normal; JSON keeps ground truth), plus 4 sample snapshots in `datasets/sample/`.

One CSV row = one device in one snapshot, with `scenario`, `is_root`, `is_affected` labels. Each snapshot has 20 devices.

Fault metrics interpolate between a mild and severe value (severity ~ U(0.15, 1)), so faults overlap each other and normal noise. Healthy devices get a 1% chance of a harmless transient spike. Faults on routers/switches degrade everything behind them.
**All numbers are illustrative assumptions, not real-world thresholds.**
